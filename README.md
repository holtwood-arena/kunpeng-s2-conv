# 鲲鹏 HPC 挑战赛 S2 · CONV 算子优化

> 一个从朴素四重循环出发，把 FP32 二维卷积优化到接近硬件峰值的学习型项目。
> 目标不是复现获奖作品，而是建立一条**可复现、可量化、可讲清**的性能优化证据链。

## 项目定位

| 项 | 内容 |
|---|---|
| 题目 | 鲲鹏高性能计算全球挑战赛 S2 · CONV 赛题（二维有效卷积，FP32） |
| 基线 | 官方 `conv2d.c`，30 行，四重循环 + `#pragma omp parallel for` |
| 评测 | 4 组官方用例，正确性容差 `1e-5`，按 GFLOPS 排名 |
| 本仓库目标 | 个人学习项目 / 面试作品，**不参与比赛**（S2 已于 2026-09-15 截止） |

## 为什么做这道题

1. **baseline 是真朴素实现**（四重循环 + `memset` 后逐个 `+=`），优化空间 10–50×
2. **完全可复现**：单文件 C + OpenMP，x86 上也能编译验证正确性
3. **指标干净**：GFLOPS，可换算峰值占比
4. **技术分层丰富**：算法选择 → 访存分块 → 指令级 SIMD → 线程调度
