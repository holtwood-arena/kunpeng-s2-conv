# 优化路线（分阶段 + 止损）

## 总原则

1. **每阶段只改一件事**，改完立刻跑四案全量对拍（正确性 + 计时）。
2. **保留每一步的原始输出**（`-fopt-info-vec`、`perf stat`、计时日志），这是面试唯一的弹药。
3. **任一阶段精度不过就回滚**，不要带着隐患往前走。
4. 本机（x86/WSL2）**只做开发与正确性验证**，性能数字一律标注「LOCAL_REFERENCE」，最终数据在鲲鹏上取。

## 阶段 0：建立可信基线（半天）

| 项 | 内容 |
|---|---|
| 目标 | 拿到自己环境下的 baseline 数字，确认对拍可用 |
| 动作 | 编译官方 `conv2d.c`；用缩小尺寸（如 512×512, k=7）跑通 4 种核形状；全量跑一次记录耗时 |
| 产出 | `bench/results/baseline.csv`、编译器向量化报告原文 |
| 验收 | 输出 `PASS`，且 naive 版本可重复复现（同机 3 次抖动 < 5%） |
| 止损 | 若环境跑不动全量，直接降规模，**不要**为了"完整"去借机器 |

## 阶段 1：标量层（1 天）

| 项 | 内容 |
|---|---|
| 改动 | 局部 `float sum` 累加器；删除 `memset`；输出一次写入 |
| 预期 | +10% ~ +40% |
| 验收 | 四案全 PASS，最大绝对误差仍为 `0.00e+00` |
| 记录 | 改前/改后 GFLOPS；说明为什么 RMW 慢（别名分析 → 无法寄存器提升） |
| 止损 | 若精度变化，说明累加顺序变了——本阶段顺序不变，应保持 0 误差 |

## 阶段 2：循环顺序与分块（1–2 天）

| 项 | 内容 |
|---|---|
| 改动 | 交换 `jk`/`ik` 与 `i` 的层级，让输入行在寄存器/L1 内复用；对输出做 4×4 或 8×4 的 tile |
| 预期 | +20% ~ +3× |
| 验收 | 四案全 PASS；核形状边界（39/41/55/81 均为奇数）要单独测尾块 |
| 记录 | L1/L2 miss 变化（若 perf 可用）；tile 尺寸扫描表 |
| 止损 | 若 tile 增大后变慢，说明 L1 已满，记录该拐点本身就是好素材 |

## 阶段 3：SIMD（2–3 天）

| 项 | 内容 |
|---|---|
| 路线 A（推荐先做） | 让编译器自动向量化：`restrict`、`#pragma omp simd`、`-fopt-info-vec` 验证 |
| 路线 B | 手写 NEON：`vld1q_f32` / `vfmaq_f32`，一次算 4 个输出（x86 上用 `-DUSE_NEON=0` 保留标量路径） |
| 路线 C（可选） | 8 输出双向量；注意寄存器压力 |
| 验收 | 四案全 PASS。**特别关注 Case1（39×39）**——公开项目正是在这里精度翻车 |
| 记录 | 峰值占比：`GFLOPS / (核数 × 频率 × 每周期 FLOP)` |
| 止损 | 若误差逼近 1e-5，立即回退到 4 输出或标量累加 |

## 阶段 4：线程与系统层（1 天）

| 项 | 内容 |
|---|---|
| 改动 | `schedule(static/dynamic)` 对比；按输出行分块避免伪共享；`OMP_PROC_BIND` / `taskset` 绑核 |
| 验收 | 线程数 1→4→8→16→32 的扩展曲线，解释偏离线性的原因 |
| 记录 | 加速比曲线 + Amdahl 估算 |
| 止损 | 若 38 线程不如 16 线程，说明伪共享或 NUMA 跨域，记录即为结论 |

## 阶段 5（可选）：算法级

大核（81×81）下可考虑 FFT 卷积 / Winograd。**仅在阶段 1–4 已完成且有余力时做**。

| 项 | 内容 |
|---|---|
| 判断依据 | 直接卷积复杂度 O(OH·OW·KH·KW)；FFT 为 O(N² log N)，核越大越有利 |
| 风险 | FP32 下 FFT 卷积误差会放大，1e-5 容差可能不保 |
| 止损 | 一周内做不出稳定通过 4 案的版本，就放弃，把过程写进「负面结果」 |

## 里程碑与验收清单

完成标准（缺一不可）：

- [ ] 四案全 PASS，误差有记录
- [ ] baseline → v1 → v2 → v3 的 GFLOPS 对比表
- [ ] 至少一张 roofline 或峰值占比图
- [ ] 至少 3 条「试了但没用」的负面结果
- [ ] 鲲鹏平台实机数据（标注 CPU 型号、线程数、绑定方式）
- [ ] 一键复现脚本
