## 分批策略

**批次 A（E01–E03）：确定性高，先把测量体系跑顺**

这三个改动几乎必然有收益，作用是校准工具链与基线，不是追求极限。

**批次 B（E04–E07）：收益大但风险上升，必须每步全量对拍**

E07 是公认的翻车点：公开项目在此处目标平台精度失败。**先写证伪条件，再写代码**。

**批次 C（E08–E10）：系统层与算法层，视余力推进**

E10 若一周内无法稳定通过四案，直接放弃，把过程写成负面结果。

## 关键实验的详细假设

### E01 局部累加器

```
假设：内层 output[...] += input*kernel 是 read-modify-write，
      且三个裸指针可能别名，编译器无法把 output 提升到寄存器。
预测：GFLOPS +10%~40%；汇编中内层对输出地址的访存指令消失。
证伪：若汇编中输出访存仍在，或 GFLOPS 落在噪声带内 → 不成立。
结果：+7.90%~+10.74%（四案中位数）。**精度预测被证伪** —— 默认编译触发 FMA 收缩，
      误差 1.22e-04 FAIL；`-ffp-contract=off` 后回到 0.00e+00。
代价：必须带编译条件，否则精度不可用。
```

### E02 行指针（**预期被证伪的对照实验**）

```
假设：二维下标 (j+jk)*inputWidth + (i+ik) 的乘法开销可观。
预测：GFLOPS +0~5%。
已知：公开项目 Parrotools/kunpengS2 的 C002 实验显示四案全部变慢（-2.6% ~ -5.7%）。
设计意图：这是一个「预期失败」的实验，用于校准判断力——
          现代编译器早已做完强度削减，凭直觉猜优化点是常见的错误路径。
代价：几乎为零，纯对照。
```

**这个实验值得单独讲**：主动设计一个预期失败的实验，然后诚实记录它失败，比做十个成功的实验更能证明方法论成熟。

### E07 8 输出 SIMD（高风险）

```
假设：4 输出受限于寄存器复用，扩到 8 输出可提升计算密度。
预测：+20%~60%。
风险：① 寄存器溢出导致 spill；② 归约顺序改变，FP32 误差累积路径变化；
      ③ 尾块处理复杂度翻倍（核尺寸 39/41/55/81 全为奇数）。
证伪：四案任一 FAIL，或误差从 0.0 升到 >1e-6 → 立即 ROLLBACK_ON_TARGET。
代价：精度余量、可维护性、可移植性（绑定向量宽度）。
```

### E10 算法级（可选）

| 方案 | 适用条件 | 主要风险 |
|---|---|---|
| im2col + GEMM | 小核（3×3~7×7） | 大核下内存放大 KH·KW 倍（81×81 → 6561×），不可行 |
| FFT 卷积 | 大核 | FP32 误差放大，1e-5 容差易破；需 padding + 重叠相加 |
| Winograd | 小核 | 大核下数值稳定性差 |

本题核尺寸 39–81，属大核区间，**im2col 和 Winograd 基本不可行**，
FFT 理论占优但精度风险高。因此 E10 默认不做，除非批次 B 提前完成。
